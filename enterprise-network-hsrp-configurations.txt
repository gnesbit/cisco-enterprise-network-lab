NOTES
-----
- HSRP version 2 is configured on every R1/R2 VLAN subinterface.
- R1 has priority 110 + preempt, so R1 is intended to be the active HSRP router.
- R2 uses the default HSRP priority (100) and acts as standby while R1 is healthy.
- HSRP group 1 is used on VLANs 10, 20, 30, 40, and 50.
- Virtual gateway addresses end in .1 on each VLAN.
- R1 physical subinterface addresses end in .2; R2 addresses end in .3.
- VLAN 40 is the 802.1Q native VLAN.
- S1/S2 FastEthernet0/2-3 form PAgP EtherChannel Port-channel1.
- S1 uses PAgP desirable; S2 uses PAgP auto.
- The .pkt running configuration contains an extra generic "standby preempt" line under R1 G0/0/0.20. It is redundant because "standby 1 preempt" is already configured, so it was omitted from this clean command list.
